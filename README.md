# Sourabh Dhulrao — Portfolio

A modern, animated portfolio website built with React, Vite, and Framer Motion.

## Features

- Smooth scroll navigation with active section highlighting
- Framer Motion animations (fade, slide, scale, stagger)
- Responsive design for all screen sizes
- Dark theme with indigo accent colors
- Sections: Hero, About, Skills, Projects, Contact

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Customize

- Update personal info in `src/components/Hero.jsx`, `About.jsx`, and `Contact.jsx`
- Add your projects in `src/components/Projects.jsx`
- Modify skills in `src/components/Skills.jsx`
- Adjust colors in `src/index.css` (`:root` variables)

## Tech Stack

- React 18
- Vite 6
- Framer Motion
- React Icons
